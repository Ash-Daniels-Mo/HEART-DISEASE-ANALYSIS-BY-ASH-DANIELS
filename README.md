# Heart Disease Prediction using Logistic Regression

This project analyzes the **Heart Disease dataset** to predict the presence of heart disease in individuals. The dataset contains medical information such as age, sex, cholesterol levels, blood pressure, and other health indicators.

The goal of this project is to:

- Explore the dataset and understand how various medical factors relate to heart disease.
- Build a **logistic regression model** to predict the likelihood of heart disease.
- Evaluate the model’s performance and interpret the results to identify the most influential factors.

This project demonstrates the application of **data analysis, feature exploration, and predictive modeling** in healthcare.
